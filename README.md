# SABAPATHY & CO | Chartered Accountants

Professional website for Sabapathy & Co, established in 1976. Providing expert Audit, Assurance, Taxation, and Management Consultancy services.

## Tech Stack

-   **Frontend**: React + Vite
-   **3D Elements**: Three.js + React Three Fiber (R3F)
-   **Styling**: Tailwind CSS + Shadcn UI
-   **Animations**: Framer Motion

## Getting Started

1.  Clone the repository.
2.  Install dependencies: `npm install`
3.  Run the development server: `npm run dev`
4.  Build for production: `npm run build`

## Project Structure

-   `src/components`: Reusable UI components and specialized 3D scenes.
-   `src/pages`: Main application pages and routes.
-   `src/hooks`: Custom React hooks for animations and state.
-   `public/images`: Branded assets and banners.
